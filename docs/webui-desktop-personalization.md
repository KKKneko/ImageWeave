# ImageWeave WebUI 桌面个性化设计

> 状态：桌面个性化 A–F 已实现并于 2026-08-03 完成阶段 F 聚焦验收；后续界面主题 G1–G3 增补亦已实现并验收
> 原 A–F 范围：桌面背景、壁纸管理、功能性动效开关、可读性与本地持久化
> 后续决策：G1–G3 已安全开放应用窗口与控件的“强调色 + 窗口底色”，详见[界面主题设计与验收](./webui-interface-theme-personalization.md)

## 1. 背景与目标

ImageWeave 当前采用“电脑桌面 + 应用窗口”的 WebUI 设计。桌面图标、任务栏、开始菜单、窗口与
`CRAWL.EXE`、`PROXY.CPL` 等程序化命名具有明确辨识度，应继续保留。

实现前的桌面背景由 `cloud-background.js` 使用 WebGL 和 `requestAnimationFrame()` 持续渲染。
阶段 A 已删除该模块、静态回退资源及初始化路径；当前正式 WebUI 只使用静态纯色或本地重编码图片
壁纸，不再提供云背景。此前的持续动画容易抢夺注意力、造成视觉疲劳，也会放大现有高对比配色带来的
刺激感。

本设计的目标是：

1. 移除桌面上的持续环境动画；
2. 保留必要、短促、能表达状态变化的功能性动画；
3. 提供明确的“开启动效 / 关闭动效”二态选项；
4. 使用若干内置纯色背景作为默认壁纸来源；
5. 支持安全导入并持久化本地静态图片；
6. 提供遮罩、布局、模糊、位置和有限窗口透明度设置；
7. 保留电脑桌面的整体交互与视觉身份；
8. 在原 A–F 阶段不调整应用窗口主配色；后续 G1–G3 以独立安全增补开放两个固定主题 Token。

核心原则：

> 桌面可以有个性，但必须安静；壁纸可以变化，但不能损害业务内容的可读性。

## 2. 已确认的产品决策

| 编号 | 决策 | 结论 |
| --- | --- | --- |
| D1 | 动效范围 | 删除所有桌面环境动画，只保留功能性动画。 |
| D2 | 动效模式 | 只提供“开启”和“关闭”两种用户模式。 |
| D3 | 默认壁纸 | 首版内置若干静态纯色背景，不使用动态背景。 |
| D4 | 自定义壁纸 | 支持用户从本地选择静态图片。 |
| D5 | 壁纸控制 | 采用遮罩、显示方式、位置、模糊、图标文字保护和有限窗口透明度。 |
| D6 | 配色重构 | **A–F 历史决策**：当时暂缓并保留应用窗口与控件配色；后续 G1–G3 决策已 supersede 其中的固定配色限制。 |
| D7 | 持久化与安全 | 采用 IndexedDB Blob、本地重编码、元数据清理、尺寸限制及安全回退。 |
| D8 | 桌面身份 | 保留桌面图标、任务栏、开始菜单、应用窗口和程序化命名。 |

以上 D1–D8 仍是桌面个性化 A–F 的实现和验收基线。仅 D6 中“继续固定应用配色”的结论后来被
G1–G3 增补取代；此后最新产品决定又取代 G1–G3 当时的 `4.5:1` 有效性门槛。当前只开放严格六位
HEX 的“强调色 + 窗口底色”，任意颜色组合都可预览、应用和持久化，界面只同步显示实际对比度，
并继续禁止自动主题换色。完整后续决策见
[《ImageWeave WebUI 界面主题个性化设计增补》](./webui-interface-theme-personalization.md)。除该明确
supersede 外，不追溯改写 A–F 对静态壁纸、动效、图片安全或桌面身份的历史决策。

## 3. 范围

### 3.1 本阶段包含

- 删除 WebGL 云背景及其持续帧循环；
- 静态桌面壁纸层；
- 内置纯色背景；
- 本地图片选择、预览、应用、删除和恢复默认；
- 功能性动效二态开关；
- 系统 `prefers-reduced-motion` 安全覆盖；
- 图片填充方式、位置、遮罩和模糊；
- 有限档位的应用窗口透明度；
- 壁纸设置的浏览器本地持久化；
- 文件类型、大小、像素、动画和元数据安全处理；
- 键盘操作、焦点、状态提示和错误回退；
- 自动化测试与静态安全检查；
- **后续主题增补及最新修订**：仅允许自定义 `--imageweave-accent` 与 `--imageweave-surface` 对应的强调色和
  窗口底色，使用严格六位 HEX 和同一完整偏好草稿；任意颜色组合均可直接预览和应用。

### 3.2 本阶段不包含

以下列表保留 A–F 的原范围语境；其中“完全不改主题 Token”已被后续 G1–G3 明确 supersede，当前
边界改为“只开放两个固定 Token，不开放任意 CSS 或自动换色”：

- 第三个及更多主题色、任意 CSS/主题文本、alpha、颜色函数或自定义 Token 名；
- 自动从壁纸提取强调色；
- 跟随壁纸、系统主题、时间或 `prefers-color-scheme` 自动替换用户颜色；
- 远程 URL 壁纸；
- GIF、APNG、动画 WebP、视频或 Shader 动态壁纸；
- 多壁纸轮播、定时切换或幻灯片；
- 云同步、账户同步或后端上传；
- 从操作系统读取桌面壁纸；
- 任意百分比窗口透明度；
- 改造成普通后台管理页。

两个已开放主题字段的完整安全模型、存储与验收边界见
[界面主题增补](./webui-interface-theme-personalization.md)。

## 4. 桌面视觉结构

桌面背景使用固定的静态分层结构：

```text
.desktop
├── .desktop-wallpaper             静态纯色或本地图片
│   ├── .desktop-wallpaper__image  仅本地图片模式启用
│   └── .desktop-wallpaper__mask   仅本地图片模式启用
├── .desktop-icons                 桌面图标
├── .application-window            应用窗口
├── .start-menu                    开始菜单
└── .taskbar                       任务栏
```

约束：

- 壁纸层必须 `pointer-events: none`；
- 壁纸层不得进入键盘焦点顺序；
- 壁纸层不得包含业务数据；
- 壁纸层不得使用 Canvas、WebGL 或持续 `requestAnimationFrame()`；
- 壁纸改变不得导致桌面图标、窗口和任务栏重新挂载；
- 图片解码失败时必须回退到默认内置纯色，不能留下空白桌面；
- 桌面图标、窗口、开始菜单和任务栏继续使用现有布局与交互模型。

## 5. 功能性动效

### 5.1 用户模式

界面只提供两个选项：

| 存储值 | 显示名称 | 行为 |
| --- | --- | --- |
| `on` | 开启动效 | 启用允许的功能性动画。 |
| `off` | 关闭动效 | 禁用所有非必要动画和过渡，状态立即切换。 |

默认值为 `on`。

现有偏好值迁移规则：

| 旧值 | 新值 |
| --- | --- |
| `system` | `on` |
| `reduced` | `off` |
| 缺失或非法值 | `on` |

用户偏好保持二态，但操作系统的 `prefers-reduced-motion: reduce` 具有更高的无障碍优先级：

```text
有效动效 = 用户选择 on 且操作系统未要求 reduce
```

当用户选择“开启”但操作系统要求减少动态效果时，设置界面应提示：

> 已开启功能性动效，但当前受系统“减少动态效果”设置限制。

不提供绕过系统减少动态效果的开关。

### 5.2 允许保留的动画

开启动效时，只允许以下功能性动画：

- 应用窗口打开、关闭和切换；
- 开始菜单展开和收起；
- 对话框出现和退出；
- 按钮按下、选择和状态切换反馈；
- 有明确起止点的加载、保存和完成反馈；
- 进度条随真实进度更新；
- 错误、警告和成功状态的短促淡入。

建议时长：

- 普通反馈：`120ms`；
- 窗口或对话框：`160–180ms`；
- 不使用超过 `220ms` 的界面过渡。

建议缓动：

```css
cubic-bezier(0.2, 0, 0, 1)
```

### 5.3 永久禁止的动画

无论动效模式如何，均不得出现：

- 壁纸移动、呼吸、缩放或颜色循环；
- 云层、粒子、扫描线、噪点或光晕循环；
- 无期限运行的装饰性 Canvas/WebGL；
- 图标漂浮、抖动或周期性闪烁；
- 仅为装饰而存在的无限 CSS animation；
- 通过自动切换壁纸制造的动态效果；
- 快速高对比闪烁。

### 5.4 关闭动效时的行为

关闭动效后：

- CSS 动画和过渡持续时间归零或降至 `0.001ms`；
- 窗口、菜单和对话框立即进入最终状态；
- 加载状态使用静态图标、文字或真实进度值；
- 不使用旋转 Spinner 作为唯一加载反馈；
- 动效关闭不能影响请求、轮询、任务状态或辅助技术播报。

## 6. 内置纯色背景

### 6.1 首版色板

首版建议提供六种低刺激纯色。颜色只影响桌面壁纸，不修改应用窗口、控件或状态色。

| ID | 名称 | 建议值 | 说明 |
| --- | --- | --- | --- |
| `graphite` | 石墨 | `#20242A` | 默认值，低刺激深色。 |
| `slate` | 岩灰 | `#384554` | 稍偏冷的中性背景。 |
| `deep-ocean` | 深海 | `#20364A` | 克制的深蓝。 |
| `forest` | 深林 | `#294039` | 克制的深绿。 |
| `plum-gray` | 灰梅 | `#403341` | 低饱和紫灰。 |
| `warm-paper` | 暖纸 | `#E7E1D6` | 柔和浅色背景。 |

默认背景为 `graphite`。

精确色值允许在视觉验收阶段小幅微调，但：

- ID 不应随色值微调而改变；
- 不使用高饱和荧光色作为默认背景；
- 不使用纯黑 `#000000` 或纯白 `#FFFFFF` 作为默认背景；
- 色板变化不得联动修改现有主题变量。

### 6.2 纯色模式行为

- 纯色模式不启用图片遮罩和图片模糊；
- 图片填充、图片位置等设置在纯色模式中隐藏或禁用；
- 切换纯色应立即预览，但只有“应用”后才写入持久化偏好；
- 恢复默认时选择 `graphite`；
- 切换纯色不能删除已保存的本地壁纸，用户仍可切回。

## 7. 本地静态图片

### 7.1 支持格式

允许输入：

- JPEG：`.jpg`、`.jpeg`；
- PNG：`.png`；
- WebP：`.webp`。

禁止输入：

- SVG；
- GIF；
- 视频；
- HTML；
- 远程 URL；
- 无法由浏览器可靠解码的文件。

即使输入 PNG 或 WebP 内含动画，也只允许保存静态结果。导入流程必须解码后重新绘制并编码，
从而去除动画帧和原始文件元数据。

### 7.2 输入限制

| 项目 | 限制 |
| --- | --- |
| 输入文件大小 | 最大 `15 MiB` |
| 输入最大边长 | 最大 `4096 px` |
| 最小尺寸 | 建议不小于 `320 × 180 px` |
| 保存格式 | 优先静态 WebP |
| 建议质量 | `0.88` |
| 保存数量 | 首版只保存一张用户自定义壁纸 |

处理规则：

1. 先验证 MIME、扩展名、大小和可解码性；
2. 按 EXIF 方向正确解码；
3. 超过最大尺寸时按比例缩小；
4. 绘制到离屏 Canvas；
5. 只导出一个静态帧；
6. 重新编码为静态 WebP；
7. 丢弃 EXIF、GPS、ICC 注释和原文件名；
8. 将最终 Blob 写入 IndexedDB；
9. 创建临时 Object URL 用于显示；
10. 替换或卸载时调用 `URL.revokeObjectURL()`。

Canvas 只允许用于一次性导入和重编码，不得用于桌面持续渲染。

### 7.3 导入交互

本地图片流程：

```text
选择本地图片
→ 本地校验
→ 解码与重编码
→ 进入预览
→ 用户调整布局和遮罩
→ 应用 / 取消
```

交互要求：

- 选择文件后不能立即覆盖现有壁纸；
- 预览阶段不写入正式偏好；
- “应用”成功后才替换 IndexedDB 中的旧 Blob；
- “取消”恢复进入预览前的壁纸和设置；
- “删除自定义壁纸”同时删除 IndexedDB Blob，并回退到默认纯色；
- 导入失败时保留原壁纸；
- 错误信息只显示安全原因，不回显本地绝对路径；
- 不在通知、日志、URL、DOM dataset 或中央 Store 中保存原始文件名与路径。

## 8. 壁纸显示与可读性设置

以下设置主要作用于本地图片模式。

### 8.1 显示方式

| 存储值 | 显示名称 | CSS 语义 |
| --- | --- | --- |
| `cover` | 填充 | `background-size: cover` |
| `contain` | 适应 | `background-size: contain` |
| `stretch` | 拉伸 | `background-size: 100% 100%` |
| `tile` | 平铺 | `background-repeat: repeat` |

默认值为 `cover`。

### 8.2 图片位置

非平铺模式提供九宫格位置：

- 左上、顶部、右上；
- 左侧、居中、右侧；
- 左下、底部、右下。

默认值为 `center`。平铺模式中隐藏或禁用位置选项。

### 8.3 遮罩

本地图片上方必须存在独立遮罩层。

| 设置 | 可选值 |
| --- | --- |
| 遮罩色调 | 深色 / 浅色 |
| 遮罩强度 | `0–80%` |
| 步进 | `5%` |
| 本地图片默认值 | 深色 `40%` |

遮罩只改善桌面区域可读性，不修改窗口内部配色。

### 8.4 模糊

只提供离散档位：

| 存储值 | 显示名称 | 建议值 |
| --- | --- | --- |
| `off` | 关闭 | `0` |
| `soft` | 轻微 | `4px` |
| `medium` | 中等 | `10px` |

默认关闭。模糊不得高于 `10px`，也不提供连续滑块，以避免持续高成本合成。

实现模糊时应适当放大图片层，防止边缘出现透明缝隙。低性能环境发生明显掉帧时允许自动关闭模糊，
但必须给出非阻断提示。

### 8.5 桌面图标保护

本地图片模式下自动启用：

- 图标文字阴影或稳定的文字底色；
- 明确的键盘焦点边框；
- 图标选中状态不依赖壁纸颜色；
- 桌面图标现有实体背景继续保留。

图标保护是固定安全策略，不提供完全关闭选项。

### 8.6 窗口透明度

窗口透明度只提供有限档位：

| 存储值 | 显示名称 | 不透明度 |
| --- | --- | --- |
| `solid` | 实色 | `100%` |
| `subtle` | 轻微透明 | `96%` |
| `soft` | 柔和透明 | `92%` |

默认值为 `solid`。

约束：

- 不允许低于 `92%`；
- 对话框、错误提示、任务栏和开始菜单保持实色；
- 透明度不得改变文字颜色或业务状态色；
- 高对比度或系统强制颜色模式下必须回到 `100%`；
- 若浏览器不支持所需合成能力，应安全回退到实色。

## 9. 设置入口与交互

新增本地桌面应用：

```text
DESKTOP.CPL
桌面个性化
```

该应用沿用现有桌面窗口模型，不改造成独立管理页面。建议同时出现在：

- 开始菜单；
- 桌面图标区域。

首版 A–F 设置结构在 G1–G3 后增补“界面主题”，当前实际结构为：

```text
桌面个性化
├── 动效
│   ├── 开启动效
│   └── 关闭动效
├── 界面主题
│   ├── 强调色
│   └── 窗口底色
├── 背景
│   ├── 内置纯色
│   └── 本地图片
├── 图片显示（本地图片模式）
│   ├── 显示方式
│   ├── 图片位置
│   ├── 遮罩色调与强度
│   └── 模糊档位
├── 窗口
│   └── 透明度档位
└── 操作
    ├── 应用
    ├── 取消
    ├── 删除自定义壁纸
    └── 恢复默认
```

交互规则：

- 所有设置先进入预览草稿；
- “应用”后才持久化；
- “取消”恢复打开设置前的状态；
- 离开存在未应用草稿的窗口时弹出确认；
- 保存过程中禁用重复提交；
- 保存成功后使用静态状态提示；
- 选择器、滑块和按钮全部支持键盘操作；
- 遮罩强度必须同时提供可读数值，不能只依赖视觉判断。

## 10. 本地持久化设计

### 10.1 存储职责

| 数据 | 存储位置 | 说明 |
| --- | --- | --- |
| 动效模式 | LocalStorage UI 偏好 | 仅保存 `on/off`。 |
| 界面主题 | LocalStorage UI 偏好 | 与其余字段一起保存完整偏好；只含规范化 `themeAccent/themeSurface` 严格六位 HEX。 |
| 当前壁纸类型 | LocalStorage UI 偏好 | `color/custom`。 |
| 内置颜色 ID | LocalStorage UI 偏好 | 只保存白名单 ID。 |
| 布局、遮罩、模糊、透明度 | LocalStorage UI 偏好 | 只保存规范化枚举和有界数字。 |
| 自定义壁纸 Blob | IndexedDB | 不进入 LocalStorage。 |
| 临时 Object URL | 仅内存 | 页面卸载或替换时撤销。 |
| 原始文件名和路径 | 不保存 | 不进入任何持久层。 |

不得将图片 Base64/Data URL 写入 LocalStorage。

### 10.2 建议数据模型

LocalStorage 中的安全偏好示例：

```json
{
  "animations": "on",
  "wallpaperKind": "color",
  "wallpaperColor": "graphite",
  "wallpaperFit": "cover",
  "wallpaperPosition": "center",
  "wallpaperMaskTone": "dark",
  "wallpaperMaskStrength": 40,
  "wallpaperBlur": "off",
  "windowOpacity": "solid",
  "themeAccent": "#46515D",
  "themeSurface": "#F4F1EA"
}
```

主题字段不建立新 LocalStorage key，也不保存 CSS 文本；严格完整偏好写入仍使用既有
`imageweave.ui:ui-preferences`。

IndexedDB 建议：

```text
数据库：imageweave-ui
版本：1
对象仓库：wallpapers
键：custom
值：{
  blob: Blob,
  mediaType: "image/webp",
  width: number,
  height: number,
  updatedAt: number,
  version: 1
}
```

不保存：

- 原始文件名；
- 原始文件路径；
- EXIF；
- GPS；
- 用户目录；
- 远程来源；
- Blob URL；
- 任意未知字段。

### 10.3 容错

- IndexedDB 不可用：允许当前会话预览，但“应用”应说明无法持久化；
- 存储配额不足：保留旧壁纸并提示空间不足；
- 偏好 JSON 损坏：丢弃非法字段并使用默认值；
- 偏好指向自定义壁纸但 Blob 缺失：自动回退默认纯色；
- Blob 损坏或无法解码：删除损坏记录并回退默认纯色；
- 写 Blob 成功但写偏好失败：回滚或继续使用上一份完整状态；
- 页面卸载：撤销所有临时 Object URL。

任何错误都不能阻止桌面壳层和业务应用启动。

## 11. 安全与隐私边界

### 11.1 文件安全

- 文件选择必须由明确用户操作触发；
- 只接受白名单图片格式；
- 禁止 SVG 和远程 URL；
- 不信任 MIME 或扩展名单独提供的类型声明；
- 必须实际解码成功后才能进入预览；
- 重新编码后才允许持久化；
- 不保留原始文件元数据；
- 不将图片上传到后端；
- 不向 diagnostics、通知或错误历史发送图片内容。

### 11.2 DOM 安全

- 壁纸只通过 Blob URL 或受控纯色 ID 设置；
- 不允许任意 CSS 字符串进入 `style`；
- 枚举值必须映射到内部固定 CSS 类或变量；
- 状态和错误使用 `textContent`；
- 不使用 `innerHTML` 展示文件名或错误；
- Blob URL 不写入 DOM dataset、LocalStorage 或中央 Store；
- 删除和替换时及时撤销 Blob URL。

### 11.3 网络边界

桌面个性化功能不得新增任何网络请求：

- 不加载远程图片；
- 不调用后端上传接口；
- 不请求颜色提取服务；
- 不发送使用统计；
- 不因壁纸设置改变现有 API、代理或凭证行为。
